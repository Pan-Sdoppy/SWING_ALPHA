# SWING_ALPHA · 主板超短/波段每日选股系统

把**交易日当天可以做「超短（隔日套利）」或「波段（超跌拐头）」的沪深主板股票全部筛出来**。
面向个人投资者，规则全部提炼自 `documents/` 内交易体系，并**优先采用其全市场回测验证后的结论**；
历史日线走 baostock，盘中实时走 akshare(新浪)，单线程 + 全量本地缓存 + 断点续传；
因子滚动统计支持 CUDA（RTX 4070 Ti Super 等），无 GPU 自动回退 CPU。

## 一、两套选股方法（与文档对应）

### 1）超短 · 隔日套利（当日封板、次日吃溢价）
- **早餐·压力位（首板~三板，以《寻找早餐》师傅原始方法为准）**：
  权重 **A1 压力位 70（决定性）/ A3 板型 15 / A2 关键位 15**；A1 不命中，A2/A3 再好也不去。
  - 当日封板、连板数 1~3、非 ST、上市≥60 日；
  - **A1 压力位（决定性）**：往左 60 日找一根“爆量K”（量≥前5日均量2倍、振幅大），
    在其**最低价（下沿）**画水平线；今日涨停价正好压在下沿下方 **0~2.5%** 即命中，可排板；
  - **A3 板型**：急拉、远离分时均价=好；贴均价横盘“红旗飘飘”=出货；围均价炸了又封=主力花钱；
  - **A2 关键位**：起涨点（近30日最低）的 ×1.5/×2 整数关口要避开，与 A1 重合时以爆量K下沿为准；
  - **备胎（仅炸板时去，不如 A1）**：B1 补缺口、B2 新高诱多；
  - **一票否决**：**左侧真空**（前60日无一日最高价>涨停价，上方一片空白）、涨停价钻进爆量K实体/影线、
    二顶、无压力又无缺口/诱多、顶部首板、老庄股、坏行情炸板不回封；
  - **环境门控**：中证1000 当日为正 **且** 市场炸板率 15%~35%（<15%死水日无溢价、>35%混乱）、非冬天（门控不过不出早餐）；
  - 一字板买不进仅记录；次日纪律：不高开集合竞价走，高开冲高走，**不格局、不持有**。
  > 说明：9·24 回测曾得出“真空溢价高、压力位反向”的相反结论，但其高溢价样本恰是最难成交的
  > 缩量/早封板，且门控用了收盘值（实盘会弱化）。经用户裁定，**以师傅原始 A1 压力位方法为准**。
- **缩量连板追板（打连板 S1，置信度 B，彩票仓 ≤20%）**：
  2~3 连板、连板期平均量比 <1.5、低位（封板价 < 起涨点×1.5）、市场非冬天、竞价高开 >2% 才追、次日不板即走。

### 2）波段 · 超跌拐头（持有数日~数周，吃回救/启动）
按《板块相位与优质个股推荐·评分规则说明》《简单哥体系_A杀解救总账》实现四类候选并打分：
- **A杀低吸（连板被套回救，全体系最强，置信度 A）**：
  近一年出现 ≥2 连板、板结束后 **≥30 交易日**、自封板价回撤 **≥25%**、至今未回封板价、**闷杀跌停≤1 次**、**市场非冬天**；
  用“出货空间 / 高位红盘量比 / 闷杀跌停”三轴判定主力是否被套；
  **高位红盘量比 ≤0.1（干净爆头）回救率 90~95%**，优先 2~3 板、回避 ≥6 板、出货完成直接剔除；
  **只买拐头阳不接飞刀**；封板价跌满 30% 为深跌买点（极端情绪日 20 日胜率 58~72%）；
  目标=封板价（前置 5% 减仓），止损=拐头低点下方；放量大阳（涨幅≥5%且量≥5日均量2倍）退出。
- **底部爆量簇启动**：近 60 日 ≥3 根量比≥3 的爆量 K 成簇、距年高回撤 ≥35%、现价站上簇均价；
  市场冬天（主跌段）禁用。
- **趋势波段（夏天延续）**：收盘创 20 日新高、站上 20/60 日线、20 日涨 >5%、缩量推升加分。
- **箱体回踩（观察型）**：现价距 zigzag(±12%) 摆动底 ±4%，等拐头阳。

> 市场”天时”四周期（夏/秋/深秋/冬）由沪深300指数与 20 日线、20 日新高判定：
> 夏=创20日新高、秋=1~3日未新高、深秋=≥4日未新高但守20日线、冬=≥4日未新高且破20日线；
> 冬天超短门控关闭、A杀禁用，predict 模式仍展示候选（标注”市场冬天”）并在末尾给出仓位建议
> （夏≤80%、秋≤50%、深秋≤30%、冬≤20%/空仓）。仓位采用文档的 4+1 结构（4 份波段 + 1 份超短），
> 程序只给建议、**不自动下单**。

## 三、安装

建议 Python 3.10~3.12（GPU 版 torch 在 3.13/3.14 暂无稳定 wheel；纯 CPU 任意 3.10+）。

```bash
pip install -r requirements.txt
```

可选 GPU 加速（RTX 4070 Ti Super，CUDA 12.1）：
```bash
pip install torch --index-url https://download.pytorch.org/whl/cu121
```
不装 torch 也能完整运行（自动用 numpy/pandas）。

## 四、使用

### 1. 更新数据（每天盘后跑一次即可）
```bash
python update.py                 # 全市场主板增量更新（默认从2016-01-01起），已最新秒级跳过
python update.py --limit 30      # 小样本验证（只更新前30只）
python update.py --codes 603396 600876
python update.py --list-only     # 只刷新股票列表/行业
python update.py --rebuild-meta  # 用已有 parquet 重建 _meta.json
python update.py --backfill 2012-01-01   # 向更早日期回填历史（可断点续传）
```

### 2. 每日选股
```bash
python predict.py                # 自动判断：盘中→实时；盘后/周末/节假日→存量
python predict.py --no-minute    # 盘中不拉分钟线（更快）
python predict.py --cpu          # 强制 CPU
python predict.py --codes 603396 # 指定股票调试
```
- **盘后运行**：基于 `data` 存量日线扫描（请先 `update.py` 落库当日数据）。
- **盘中运行（工作日 9:30~15:00）**：拉新浪全市场快照，在**内存**里追加当日临时 K 线
  （仅缓存到 `data/intraday`，**不写入正式增量、不替代 update**），并对当日触板股拉分钟线
  判断封板时间/开板/红旗；节假日快照时间戳非实时会自动回退盘后。

输出：**【超短·隔日套利】** 一张表 + **【波段·超跌拐头】** 按类型分表（A杀低吸 / 趋势波段），
`所属板块`列固定最右；predict 模式即使市场冬天也展示全部候选（备注标注环境），末尾附统一选股建议
（仓位/风险提示）；CSV 留档 `data/processed/predictions/`。

### 3. 历史回测（2017 至今，严格无未来函数，写死最优参数）
数据从 2016 年起下载（给 250 日因子留预热），回测从 2017 年开始：
```bash
python backtest.py                 # 全市场回测 2017-01 至今
python backtest.py --cpu           # 强制 CPU
python backtest.py --codes 600000 000001   # 小样本调试
python backtest.py --start 2020-06-01      # 自定义起点
```
- **写死最优参数**（经全参数网格验证后锁定）：超短 **top1**（t日涨停价排板买、t+1开盘卖）；
  波段 **bigbar/top3**（t+1开盘买，放量大阳线退出：涨幅≥5%且量≥5日均量2倍，最长持有20日兜底）。
- **数据隔离**：信号在交易日 t 只用 ≤t 数据（与 predict 同一套因果因子/扫描）；
  止损/持有期/退出全部只用入场之后的行情；t+1开盘已跌破止损视为支撑破位、放弃成交（不接飞刀）。
- **成本**：买卖佣金各 0.025%、卖出印花税 0.05%、双边滑点各 0.05%。
- **输出**：【超短】与【波段】各一张总表 + **2017-2025 各年度** 与 **2026 各月度** 明细
  （交易数/胜率/平均收益/最大回撤/平均持仓日），CSV 留档 `data/processed/backtests/`。
- 超短以”当日排板成交”为假设，属偏乐观上限（涨停封死未必买得到），实盘可成交性需自行打折。

## 五、数据缓存与异常隔离（设计要点）

- **永久缓存**：每股一个 `data/raw/{code}.parquet`，单股失败互不影响。
- **元数据 `_meta.json`**：记录每股最新日期/行数，启动秒级判断是否增量，可从 parquet 重建。
- **股票列表 `_stock_list.csv`**：缓存 7 天，接口失败自动回退过期缓存；
  **无论在线还是读缓存，返回前都强制“剔 ST/退市 + 仅主板(60/00)”**（当前干净主板非 ST 约 3050 只）。
- **因子缓存** `factor_data.parquet`：数据未变直接复用，盘中临时数据不写缓存。
- **增量**：本地最新日期之后才下载；工作日 1 天窗口、周末 3 天窗口；盘前空下载不更新元数据。
- **异常隔离**：单股失败递增重试 3 次（1s/2s 退避）、15s socket 快判；连续 3 只失败判定连接老化，
  自动 logout/login 重连；第一轮后对失败股补下载 2 轮；**网络失败(None) 与节假日无数据(空表)严格区分**。
- **单线程**：akshare 内嵌 V8 引擎不支持多线程；配合元数据，已有数据秒级 skip。
- **清洗**：停牌(量=0)、收盘价 ≤0 或 ≥10000 剔除；次新（<60 日）不入可交易池，波段评分要求 ≥250 日，
  近 60 日日均成交额 < 5000 万剔除。
- **baostock 访问限制守卫**：官方日请求≤5万次（超量入黑名单），所有查询经 `BaoStockSession` 统一计数
  （`data/raw/_baostock_usage.json` 持久化，达4.5万警告、达5万拒绝）；禁止并发连接（全局单例会话守卫），
  行业映射用 `query_all_industry()` 单次全量查询（仅1次请求），严禁多进程。

## 六、调参

所有阈值集中在 `config/strategy_params.py`（股票池、早餐、缩量连板、A杀、底部簇、
趋势、箱体、市场周期、仓位、输出数量）。修改后无需重新下载数据，重跑 `predict.py` 即可
（因子缓存按数据日期自动失效）。
